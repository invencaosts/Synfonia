## 🔧 Tecnologias

Este projeto foi desenvolvido com:
- Java 21
- Spring Boot
- PostgreSQL
- MongoDB
- Docker
- Git e GitHub

## 📖 Projeto

O **Synfonia** é o backend da plataforma de música Synfonia. Expõe a API REST responsável por autenticação, perfis de usuário, playlists, histórico de reprodução, avaliação de álbuns e integração com os serviços do Spotify e do YouTube Music.

O frontend, que consome essa API, fica em [`invencaosts/Synfonia-Front`](https://github.com/invencaosts/Synfonia-Front).

- Java 21
- Spring Boot
- PostgreSQL
- MongoDB
- Docker
- Git and GitHub

## 📖 Project

**Synfonia** is the backend of the Synfonia music platform. It exposes the REST API responsible for authentication, user profiles, playlists, playback history, album ratings, and integration with Spotify and YouTube Music.

The frontend that consumes this API lives at [`invencaosts/Synfonia-Front`](https://github.com/invencaosts/Synfonia-Front).
